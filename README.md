## 📖 Overview

A **full adder** is a combinational circuit that performs binary addition. This
project builds a **2-bit full adder** with the **cascade method**: two 1-bit adders
chained together, where the carry-out of the first stage becomes the carry-in of the
second — eliminating any need for an external carry input.

The circuit takes two 2-bit numbers and produces a complete sum with final carry:

```
 Inputs :  A1 A0   +   B1 B0
 Outputs:  Sum2 Sum1  and  Carry-out (Cfinal)
```

---

## 🧩 Design Approach

Instead of only basic gates, each output is realised with **multiplexers** driven by
the derived truth tables:

| Output | Implementation |
|:--|:--|
| **Sum1** | **8:1 multiplexer** — inputs I0–I7 assigned from the Sum1 truth table |
| **Sum2** | **2:1 multiplexers** — select between logic conditions |
| **Carry (Cfinal)** | **2:1 multiplexer** + **AND / OR gates** |
| Select lines | The input variables `A1 A0 B1 B0` drive the MUX select lines |

### 🔄 Cascade structure

```
   A0 B0 ──▶┌───────────┐
            │  1-bit    │─── C1 ──┐
            │  adder    │──▶ S1   │
            └───────────┘         ▼
                          ┌───────────┐
   A1 B1 ────────────────▶│  1-bit    │───▶ Cfinal
                           │  adder    │───▶ S2
                          └───────────┘

          Sum1 ◀── stage 1        Sum2 ◀── stage 2
```

The carry generated by the LSB stage is correctly propagated into the MSB stage,
completing the 2-bit addition.

---

## 🔧 Working Principle

1. **Stage 1 (LSB):** add `A0 + B0` with an assumed initial carry of `0`.
2. **Stage 2 (MSB):** add `A1 + B1` plus the carry `C1` from stage 1.
3. Each multiplexer's **data inputs are set from the truth table**, and the input
   variables act as **select lines** to route the correct value to the output.

## 🧪 Verification

The design was simulated and every input combination (16 states of `A1 A0 B1 B0`) was
applied. The observed outputs **matched the truth tables** for Sum1, Sum2, and Carry —
confirming the correctness of the multiplexer-based cascaded design.
